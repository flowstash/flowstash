# flowstash-runtime

This package provides the actual runtime engine and bootstrap layer for the flowstash platform. It depends on `flowstash-lib` and `flowstash-clients`.

## Installation

```bash
pip install flowstash-runtime
```

## Usage

```python
import flowstash.runtime

# Initialize the runtime engine
```

For full documentation and details on how this fits into the larger ecosystem, please refer to the [flowstash Monorepo Root](https://github.com/TODO/flowstash).
